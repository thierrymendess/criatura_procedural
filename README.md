# Procedural Creature

Projeto de criatura procedural feito com:
* HTML
* CSS
* JavaScript
* Canvas API

A criatura segue o mouse usando segmentos animados.

---

# Estrutura

```txt
procedural-creature/
│
├── index.html
├── README.md
│
├── css/
│   └── style.css
│
├── js/
│   └── main.js
│
└── assets/
```
# Funções

* movimento procedural
* criatura seguindo o mouse
* animação em tempo real
* fundo escuro
* efeito orgânico
